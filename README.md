# Enthernet

Để hiểu Ethernet trên STM32, bạn cần biết vai trò của MAC (Media Access Controller – bộ điều khiển truy cập môi trường) và PHY (Physical Layer – tầng vật lý).

MAC (Media Access Controller):
MAC nằm bên trong vi điều khiển STM32. Nó xử lý các chức năng của tầng liên kết dữ liệu như đóng gói khung (framing), địa chỉ hóa, và quản lý các gói tin Ethernet.

PHY (Physical Layer):
PHY thường là một chip ngoại vi, được nối với STM32 qua giao tiếp RMII hoặc MII. Nó quản lý việc truyền/nhận tín hiệu điện thực tế, phát hiện trạng thái kết nối (link) và thương lượng tốc độ với cáp Ethernet.

Kết hợp lại, MAC và PHY tạo thành giao diện Ethernet hoàn chỉnh. STM32 cấu hình MAC, trong khi PHY đảm bảo kết nối vật lý với mạng. Việc thiết lập đúng địa chỉ PHY và các chân (pins) trong CubeMX là rất quan trọng để Ethernet hoạt động.
